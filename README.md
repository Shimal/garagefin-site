# GarageFin website

Official static website for GarageFin, published with GitHub Pages.

- Home: `https://shimal.github.io/garagefin-site/`
- Support: `https://shimal.github.io/garagefin-site/support/`
- Privacy: `https://shimal.github.io/garagefin-site/privacy/`

The site supports English, Arabic, German, Spanish, French, Ukrainian, Georgian, Russian, and Turkish. It has no build step, tracking, analytics, cookies, or external runtime dependencies.
